NAMUA PROJECTS · PANDUAN PEMASANGAN

Mulai dari sini.

Admin menyiapkan server sekali. Setelah itu, lanjutkan melalui formulir di browser. Paket dan kuota lisensi sudah dipilih penjual. Tidak ada batas waktu untuk mulai memasang.

  1. ANDA

    Ekstrak ZIP lengkap

    Hasil ekstrak adalah satu folder finance. Unggah seluruh isinya ke folder baru di server. Jangan hanya mengambil TAR atau menimpa aplikasi yang sudah berisi data.

    Panduan ini ada di folder utama Finance. Jika HTML sulit dibuka, baca MULAI-DI-SINI.txt di sebelah file ini.

  2. ADMIN SERVER

    Siapkan website dan database kosong

    Buat website HTTPS. Arahkan folder website (document root) ke finance/public, bukan seluruh folder Finance. Buat database kosong dan user yang memiliki akses ke database tersebut.

    Linux x86_64, PHP 8.1 dan MariaDB 10.11. Panel bebas, tidak wajib aaPanel. Windows belum disetujui untuk paket ini.

  3. ADMIN SERVER · TERMINAL SEKALI

    Jalankan persiapan

    Buka terminal di dalam folder finance hasil ekstrak, lalu jalankan:

    sudo sh tools/install/portable/prepare.sh

    Jika terminal sudah root, hilangkan sudo. Ikuti pertanyaan akun website dan alamat aplikasi, periksa target, lalu ketik SIAP. Tunggu Persiapan berhasil.

    Izin folder dan jadwal pendamping disiapkan otomatis; tidak perlu memasang cron satu per satu. Perintah tidak memasang atau mengganti PHP, database, maupun website lain.

  4. ANDA · MELALUI BROWSER

    Isi formulir pemasangan

    Buka alamat website Anda ditambah /setup. Kode setup ada di finance/private/delivery/KODE-SETUP.txt; buka melalui File Manager atau berkas lokal, bukan URL publik.

    Isi alamat aplikasi, host, port, nama database, username dan password database. Klik Uji koneksi & database kosong. Setelah lulus, isi akun admin pertama, periksa ringkasan, lalu klik Pasang dan aktifkan.

    Tidak perlu mengimpor SQL manual. Pemasang membuat tabel dan mengaktifkan lisensi.

  5. ANDA

    Masuk ke Finance

    Tunggu hasil berhasil, lalu klik Masuk ke Finance. URL dan database tersimpan di finance/config/customer.json. Tidak perlu mengedit application/config/config.php atau database.php.

    Minta penjual memastikan hasil pemasangan, lisensi server, dan laporan koneksi sudah diterima di Control.

Berkas privat tetap privat.

Kode akses halaman unduh berbeda dari kode setup. Jangan membagikan ZIP, password, atau isi folder private dan config kepada publik. Jangan menghapus panduan ini; ia bagian dari paket yang diperiksa pemasang.

Kalau belum berhasil
“Paket belum disiapkan” di /setup
Admin belum menyelesaikan langkah 3. Jalankan perintah persiapan yang sama dan baca hasilnya. Jangan memakai chmod 777.
Uji database gagal
Periksa nama database, user dan password di formulir. Database harus sudah ada dan kosong; jangan menghapus data lama untuk memaksa pemasangan.
Muncul SETUP_PERMISSION_EXPIRED?
Paket alpha.20 tidak memakai batas pemasangan satu jam. Pesan ini menunjukkan paket lama. Minta paket terbaru dari penjual; jangan menimpa folder yang sudah disiapkan atau berisi data.
Izin dicabut atau kuota penuh?
Hubungi penjual. Tidak ada tenggat pemasangan, tetapi setiap server tetap harus diaktifkan sesuai paket dan kuota pembelian. Menyalin ZIP tidak menambah hak server.
Koneksi terputus atau pemasangan sudah dimulai
Periksa status pemasangan dan hubungi penjual jika ditahan. Jangan mengulang SQL, menghapus journal, atau mengganti identitas.
